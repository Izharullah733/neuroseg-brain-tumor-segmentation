# Figure provenance

Training curves are generated from local JSONL experiment logs. Validation
examples show each case's slice with the largest reference tumor area; they are
not selected by best prediction quality. All four validation cases are shown.

MRI examples and label overlays derive from the Medical Segmentation Decathlon
Task01 BrainTumour (BraTS-derived) data under CC-BY-SA 4.0. Preserve attribution
and the applicable share-alike license when redistributing these data-derived
figures. See ../DATASET_CARD.md for source and citations.

Colors: green edema, orange non-enhancing tumor, pink enhancing tumor.
Figures are developmental research outputs, not clinical demonstrations.
